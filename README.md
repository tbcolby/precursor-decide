## What This Is

The Decision Engine is a TRNG-powered board game companion for Precursor. Eight tools in one app: dice roller, coin flipper, card drawer, Magic 8-Ball, custom spinner, scoreboard, turn tracker, and tournament bracket.

Every random outcome is generated by Precursor's hardware true random number generator — quantum noise from physical transistor phenomena, not algorithms, not seeds, not PRNGs. When you roll dice on this device, the universe is literally choosing the result.

This is not a novelty. On a device with a hardware TRNG, this is the most honest set of dice, coins, and cards that has ever existed in anyone's pocket.

---

## Why This Project

Board games have a logistics problem. Dice get lost. Cards get bent. Score is kept on a napkin that gets wet. Nobody can agree whose turn it is. And every dice app on every phone uses `Math.random()` or `arc4random()` — algorithmic pseudorandomness that is *deterministic by design*.

Precursor is the only mobile device with a hardware true random number generator. The Decision Engine turns this into a practical tool for game night: eight distinct randomization and tracking tools, all powered by quantum noise, all stored in hardware-encrypted flash, all running on a device with no internet connection to leak your data.

Your dice are honest. Your cards are shuffled by the universe. Your scores are encrypted. Your tournament brackets are truly random.

---

## Why Precursor

**Hardware TRNG.** The central feature. Precursor's TRNG produces random numbers from physical noise — avalanche noise in transistor junctions. This is fundamentally different from every software RNG. The output is non-deterministic, non-reproducible, and unbiased. Rejection sampling eliminates modulo bias. Every die roll, coin flip, card shuffle, and spinner result comes from this source.

**Physical keyboard.** Player names, score adjustments, modifier values — all typed directly. No on-screen keyboard. No autocorrect. Fast data entry during game play.

**1-bit display.** ASCII art dice faces, card faces, coin art — all rendered crisply on the monochrome display. No color approximation. Clean, readable numbers at any viewing angle.

**PDDB encrypted storage.** Scoreboard state persists across power cycles in hardware-encrypted flash. Game state is private by design.

**No network.** Nobody can accuse you of rigged results. The device has no way to communicate the random seed (there is no seed) or the sequence (it's non-deterministic). The TRNG output is as close to "provably fair" as physically possible outside of a sealed casino die.

**Portable.** Fits in a pocket. Comes to every game night. Never needs batteries for dice (the device battery runs the TRNG, the display, and the app simultaneously).

## Features

### 1. Dice Roller
- Standard RPG dice: d4, d6, d8, d10, d12, d20, d100
- 1-20 dice at once
- Roll modifiers: +N / -N
- Advantage / Disadvantage (D&D 5e: roll twice, take higher/lower)
- Exploding dice (if max value, roll again and add)
- Drop lowest (e.g., 4d6 drop 1 for stat generation)
- Natural 20 / natural 1 detection on d20
- ASCII art for d6 faces
- Roll history (last 20)

### 2. Coin Flip
- Heads/Tails with large ASCII art
- Flip 1-20 coins simultaneously
- Custom side names (Yes/No, Pizza/Sushi, etc.)
- Streak counter for consecutive results

### 3. Card Drawer
- Standard 52-card deck with optional jokers
- Draw 1-9 cards at a time
- Deck tracking (cards remaining)
- ASCII art card faces with suit symbols
- Shuffle/reset deck

### 4. Magic 8-Ball
- 20 classic responses (10 affirmative, 5 non-committal, 5 negative)
- ASCII art 8-ball display
- Sentiment indicator (+, ?, -)

### 5. Spinner
- 2-12 custom segments
- Named segments with optional weights
- Weighted probability selection
- Add/remove/edit segments

### 6. Scoreboard
- 2-8 players with custom names
- Add/subtract points with configurable increment
- Round tracking
- Sort by score
- Persistent save to PDDB

### 7. Turn Tracker
- 2-20 players in order
- Current player highlighted
- Auto-advance on Enter
- Random turn order (TRNG shuffle)
- Skip/remove player
- Round counter

### 8. Tournament Bracket
- 2-16 players
- Single elimination
- TRNG-seeded random matchups
- Advance winners manually or randomly
- BYE handling for non-power-of-2 counts
- Champion declaration

## Architecture

```
src/
  main.rs         — Xous event loop, GAM registration, TRNG init
  app.rs          — Master state machine, 8 tool handlers, text input
  rng.rs          — TRNG wrapper (rejection sampling, Fisher-Yates, weighted pick)
  dice.rs         — Dice roller engine (d4-d100, modifiers, advantage, exploding)
  coin.rs         — Coin flipper (multi-flip, custom sides, streaks)
  cards.rs        — Card drawer (52-card deck, draw tracking, ASCII art)
  eightball.rs    — Magic 8-Ball (20 classic responses)
  spinner.rs      — Custom spinner (weighted segments)
  scoreboard.rs   — Multi-player scoring with rounds
  turns.rs        — Turn tracker with skip/randomize
  tournament.rs   — Single elimination bracket generator
  ui.rs           — Rendering for all screens (header/footer/content)
  storage.rs      — PDDB persistence (scoreboard, spinner, coin names)
```

### Module Independence

The tool modules (`dice.rs`, `coin.rs`, `cards.rs`, `eightball.rs`, `spinner.rs`, `scoreboard.rs`, `turns.rs`, `tournament.rs`) have minimal dependencies:
- `rng.rs` depends only on the `trng` crate
- Tool modules depend only on `rng.rs` and `alloc`
- `scoreboard.rs` uses `serde` for PDDB persistence
- No tool module depends on any other tool module
- No tool module depends on GAM or any Xous graphics types

### TRNG Pipeline

```
Hardware TRNG (quantum noise)
    → trng::Trng::get_u32()
    → Rng::range() with rejection sampling (eliminates modulo bias)
    → Rng::roll_die() / flip() / shuffle() / weighted_pick()
    → Tool-specific logic (dice, cards, spinner, etc.)
```
